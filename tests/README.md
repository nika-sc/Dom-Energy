# Тесты платы

`tests/test-board.py` — сквозные проверки живого устройства по HTTP.
Только чтение: тесты не пишут на карту и не переключают реле.

## 1. Что нужно

- плата в той же сети, что и компьютер;
- известен её IP (serial `STATUS` или `NET`, либо экран/роутер);
- прошивка собрана и залита;
- на карте есть история (`/energy.csv`), иначе часть проверок
  предупредит о нехватке данных;
- Python 3.9+; сторонние пакеты **не нужны** (только стандартная библиотека).

## 2. Запуск

```powershell
# из корня репозитория
$env:BOARD_URL = "http://192.168.1.50"   # ваш IP платы
python tests\test-board.py
```

Быстрый режим (без проверки качества мощности):

```powershell
python tests\test-board.py --quick
```

Проверка мощности за всю историю (медленнее):

```powershell
python tests\test-board.py --all-days
```

Тарифы по умолчанию — пример 8.39 / 4.49. Если у вас другие:

```powershell
$env:TARIFF_DAY = "7.50"
$env:TARIFF_NIGHT = "3.90"
python tests\test-board.py
```

Часовой пояс платы (по умолчанию UTC+3):

```powershell
$env:BOARD_TZ = "3"
```

## 3. Что проверяется

| Группа | Проверки |
|---|---|
| Доступность | `GET /`, `/data`, `/days`, `/history`, `/events`; мусорная дата отклоняется |
| Контракт | в `/data` есть `v`, `temp`, `p`, `amp`, `e`, `r`, `tkwh`, `tcost`, `ykwh`, `ykost`, `mkwh`, `mcost`, `tariff`, `rssi`, `sdRows` |
| Границы | 180–260 В, 15–60 °C, 0–5000 Вт, 0–25 А; счётчик > 0; карта не пуста |
| Целостность | счётчик не убывает; все часы за 2 суток заполнены (норма 113–120 строк/час) |
| Мощность | интеграл мощности сходится со счётчиком (0.75–1.33); нет «застывших» часов |
| Математика | сумма часов = «сегодня»/«вчера»; пик ≥ средняя; стоимость по зонам; прогноз |
| Стабильность | 10 загрузок страницы, 10 запросов `/data`, нет перезагрузки, heap не просел |

Тест мощности — главный: он ловит случай, когда в CSV пишется 19 Вт, а
счётчик за час прибавил 0.32 кВт·ч. Тогда интеграл даёт 0.019 вместо 0.32,
и расхождение видно сразу.

## 4. Вывод и код возврата

```
ГРУППА            ПРОШЛО
доступность       5/5
контракт          8/8
...
ВСЕГО: 42 из 42
```

- `0` — всё прошло (предупреждения не считаются провалом);
- `1` — есть провалы.

Предупреждения (`ВНИМ`) — это, например, одна дырка в истории после
перепрошивки. Они не ломают публикацию, но показывают состояние.

## 5. Если тесты не идут

| Симптом | Что проверить |
|---|---|
| `urlopen error timed out` | IP платы, Wi-Fi, `ping` |
| `Connection refused` | плата не подняла `WebServer`; serial `STATUS` |
| `/data` без полей | старая прошивка; перепрошить 4.4 |
| «строк с датой найдено 0» | карта пуста/не читается; serial `DIAG` |
| «часы заполнены» с дырками | плата стояла/перепрошивалась; это предупреждение |
| «интеграл мощности» врёт | локальный DP 6 устарел; смотреть облако Tuya |

`/full` может отдавать сотни килобайт; на медленной сети тест идёт долго.
Это нормально: таймаут в скрипте — 180 с.
