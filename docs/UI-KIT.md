| Радиус кнопки | 8 px |

| Подписи | 11–13 px, верхний регистр только в заголовках |
| Тач-цель | ≥ 44 px |

## Правила

1. Новая карточка — сначала макет на 240×320, потом код.
2. Любой новый цвет — только из палитры, не «на глаз».
3. Все скины должны оставаться читаемыми: контраст текста ≥ 4.5:1.
4. Печать и веб используют одну типографику; в приложении — та же сетка 4/2/1 колонки.
