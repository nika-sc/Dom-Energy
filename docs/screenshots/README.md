Как они сделаны: скриншоты 480×640 увеличены до 720×960 (×1.5, без
сглаживания — пиксели остаются резкими), зоны обведены рамками разных
цветов, номера на рамках совпадают с номерами пояснений в колонке справа.
Подписи стоят вне экрана, поэтому ни одна цифра не закрыта.
Скрипт: `annotate.py` (Python + Pillow, шрифт Segoe UI).

Скриншоты ПК сняты при живом подключении. Адрес платы на них приведён к
`192.168.1.51` — так же, как `publish.py` заменяет реальные адреса в текстах
(`192.168.0.N → 192.168.1.N`), поэтому реальная подсеть в публичную версию не
попадает.
