# Чек-лист релиза (обязательный)

Правило проекта: **каждый релиз обновляет GitHub целиком**. Если что-то из списка
не сделано — релиз не считается выпущенным.

## 1. Код и прошивка
- [ ] `FW_VER` в `firmware/cydv4/cydv4.ino` = новой версии
- [ ] `web/page.html` собран в `page_html.h` (`python web/build_page.py`)
- [ ] прошивка собрана: `arduino-cli compile --fqbn esp32:esp32:esp32:PartitionScheme=min_spiffs`
- [ ] бинарник прошит по OTA, `boots.log` содержит `rr=OTA`, поле `fw` в `/data` отдаёт новую версию
- [ ] прогон тестов: `/range` на всех периодах, границы, `/tariff`, `/sound`, `/beep`, `/gapfill`, `/files`

## 2. Документация
- [ ] `CHANGELOG.md` — новый раздел сверху, с датой и списком изменений
- [ ] `README.md`:
  - [ ] бейдж версии (`img.shields.io/badge/версия-CYD--X.Y`)
  - [ ] раздел «Что нового в X.Y»
  - [ ] таблица HTTP-эндпоинтов и команд пополнена
  - [ ] скриншоты актуальны, старые заменены
  - [ ] «Как проверить за 5 минут» соответствует текущей версии
- [ ] `BUILD.md` — если менялись схема разделов, зависимости, размеры
- [ ] `docs/АРХИТЕКТУРА.md`, `docs/PITFALLS.md` — если менялась логика или грабли
- [ ] `docs/WIRING.md` — если добавлено железо (например, динамик)
- [ ] `docs/README.md` — индекс: новые файлы (release notes, чек-лист)
- [ ] `docs/DATA-POLICY.md` — если изменился состав или формат сохраняемых данных
- [ ] `docs/screenshots/README.md` — какие кадры новые, какие устарели
- [ ] `docs/RELEASE-X.Y.Z.md` — описание релиза (без пометки «черновик»)

## 3. Артефакты
- [ ] `dom-energy-X.Y.Z-firmware.zip` (bin, ino, page_html.h, web/page.html, build_page.py)
- [ ] `dom-energy-X.Y.Z-windows.zip` (DomMonitor.ps1, tg-relay.ps1, README)
- [ ] скриншоты в `docs/screenshots/` (web, pc, board), при необходимости — новые аннотированные

## 4. Git и публикация
- [ ] коммит и пуш в `nika-sc/Dom-Energy` (`main`)
- [ ] тег `vX.Y.Z` (аннотированный, с описанием)
- [ ] зеркало в Gitea синхронизировано
- [ ] GitHub Release: текст, файлы, скриншоты
- [ ] `docs/RELEASE-X.Y.Z-draft.md` удалён или превращён в описание релиза

## 5. После релиза
- [ ] посты (Instagram, Threads) по текстам из `REPORT-<версия>/social-X.Y.Z.md`
- [ ] полный архив платы (дамп 4 МБ + SD) в `DEVICE-ARCHIVE/`
- [ ] проверка через сутки: пропуски, погода, звук, уведомления

## 6. Если что-то не влезло
Не «дописывать потом»: либо переносится в следующий релиз и явно указано
в README/CHANGELOG как известное ограничение, либо релиз не выходит.
